# FindIt — Lost & Found Campus Portal

FindIt is a campus web application designed to help
students report, search, claim, and recover lost items.

## Planned Technology Stack

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Git and GitHub

## Initial Features

- Campus homepage
- Lost and Found reporting
- Item search and filtering
- Ownership verification
- Claim management
- Resolved items archive
